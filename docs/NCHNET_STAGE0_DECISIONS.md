## 3. 论文歧义的默认处理决定

“补充约定”表示论文不足以唯一确定实现时的选择，不代表已找回历史实验设置。以后若改变以下决定，需记录原因并使用不同实验配置。

### D01. 骨干架构、冻结与梯度

- **论文明确/冲突：** p8、16 使用 CLIP ViT-B/16；p6 的 BERT 描述与之不同。p11 写冻结编码器，p16 又为 CLIP 骨干指定 `1e-5` 学习率。
- **决定：** 采用 CLIP，以 §4.2 的骨干微调作为默认训练预设；另保留明确的冻结骨干预设，分别记录结果。
- **补充约定：** NAC 纠正后的重编码复用当前 text encoder，仅该次计算停止梯度；不额外复制一个编码器。这不等于主编码器参数全程固定。二值检测和 `argmax` 不可微，生成器通过 `L_gen` 学习，不宣称检索梯度能穿过 token 替换训练生成器。

### D02. NAC 的监督来源与掩码

- **论文明确：** 式 (6)–(8) 用视觉余弦相似度产生检测掩码 `M`；式 (27) 只在检测位置使用干净 token 监督，但未交代不同句式的生成文本如何与人工文本逐 token 对齐。
- **决定：** 区分主输入、干净目标、目标有效掩码、人工腐蚀真值和视觉检测掩码。生成 CE 的位置固定为 `M & target_valid_mask`；人工腐蚀真值用于检测评估，不替代 `M`。
- **归约：** `L_gen` 对全部有效 token 求均值；没有有效位置时返回可反传零值并记录有效 token 数，避免对空张量计算 CE。
- **补充约定：** 先从人工文本构造位置可对齐的普通属性 token 替换，保持 BPE 位置及长度对应，验证和训练纠错器。腐蚀规则、比例及种子均须进入后续实验配置，属于新增训练约定。
- **边界：** 不能以 `<|mask|>` 替换作为主要受控噪声，因为式 (8) 将其排除。真实 LLM 改写若无对齐干净目标，`target_valid_mask` 全为假，不伪造逐位置目标；可以参与纠正后的检索学习，但不直接贡献生成 CE。受控训练的有效性仍须通过真实噪声实验验证。

### D03. NAC 的执行方式和推理范围

- **论文明确/冲突：** p11 明确训练时执行纠正，p22 又将 NAC 计入推理开销，但没有定义检索时用哪张图像纠正查询。
- **决定：** 默认 NAC 用于训练；评估分别编码查询文本与图库图像，不使用查询真实匹配图进行纠正。候选相关的重排属于另一种推理协议，当前不纳入默认方案。
- **接口：** 生成器对外接收 `[B,L,512]`，输出 `[B,L,V]`；内部维度转换明确，不依赖旧 CLIP 的 batch 拆分或 `modal` 特例。
- **补充约定：** 保留现有六层 Transformer 修复器的设计方向，采用非自回归并行 token 预测。论文将其称为 decoder，但未指定独立 memory 或因果掩码；不自行添加自回归过程。保留原 EOT 位置，替换候选排除控制 token，避免破坏句子边界。

### D04. A2DFP 的维度、局部范围与残差

- **论文明确：** 式 (16)–(21) 为重要性和上下文门控、soft pooling、Linear-ReLU-Linear 与残差融合；检索维度为 512，但 p16 又写 A2DFP 维度 2048。
- **补充约定：** 池化保持 512 维，增强投影采用 `512 → 2048 → ReLU → 512`，将 2048 解释为隐藏维度，满足同维残差融合。视觉、文本分支同结构、非共享参数。
- **决定：** 权重使用 `softmax(importance * context)`，不额外乘 `1/N`；融合系数 0.5。视觉局部聚合排除 CLS，CLS 作为全局残差；文本局部聚合排除 padding 和控制 token，EOT 为全局残差。无有效局部 token 时回退全局表示。
- **尺度：** 不在残差融合前擅自分别归一化两支；相似度计算处统一归一化。上述局部 token 范围和空输入处理属于补充约定。

### D05. CDFP 的作用位置、尺度与双模态合并

- **论文明确/冲突：** 式 (22)、(23)、(28) 使用余弦最难正样本、Top-2 负样本均值和 margin 0.1；p16 的温度 0.07 未出现在该公式中。
- **决定：** 默认使用原始余弦 hinge loss，不除温度。选项应明确标识该公式模式，不能让温度参数看似生效却被静默忽略。
- **补充约定：** CDFP 作用于残差融合后的最终检索表示；CDFP-only 作用于 CLIP 全局表示，不隐式启用 A2DFP。视觉/文本分别计算，`L_cdfp = (L_visual + L_text) / 2`，再统一乘 0.1。
- **边界：** 排除样本自身；不足 2 个负样本则使用全部有效负样本。仅对同时有正负样本的 anchor 求均值；无有效 anchor 时返回可反传零值并记录数量。CDFP 开启时使用身份采样，优先选择同身份不同原图，记录重复采样情况。

### D06. 损失定义和额外目标

- 按式 (24)–(29)：共享无偏置 ID 分类器，label smoothing 为 0.1；ID 为两模态 CE 之和，保持论文尺度。
- 默认总损失：`L_sdm + L_id + 0.1 * L_cdfp + 0.5 * L_gen`，关闭的模块对应项为零。
- MLM、TTC 和旧 NAM 的额外目标不默认混入；论文未给出公式的 A2DFP 辅助正则不自行添加。
- 模型输出明确区分总损失、原始损失分量和指标；训练只反传明确的总损失，不按键名中是否包含 `loss` 自动求和，避免诊断分量被重复计入。

### D07. 扩充规模与数据来源

- 按 p7–8 方法描述：30 个模板、每原图 2 条扩充描述；身份特定 DreamBooth + LoRA，rank 128、400 张先验图像、8 字符身份标识；每原图 20 张候选，按与该原图的相似度保留 10 张。
- 文本与图像如何组合成训练对未完全说明。补充约定为：保留原始对；扩充文本与其源图配对；生成图先获得自身描述，并保存源图/身份关系，不自动把所有文本和生成图做笛卡尔积。
- 先确定训练划分，再生成和筛选；只扩充训练部分。记录源图、原身份、模板、模型版本、生成参数、候选排名和实际数量。论文样本数表格与方法描述不完全相符时，以此明确规则生成并报告实数，不强行凑表格数量。

### D08. 选模与实验口径

- 先验证 RSTPReid 单数据集基线；完整实验再按全量 SYNTH-PEDES 预训练、直接迁移、各目标集分别微调执行。
- 有官方验证集时按验证集 Rank-1 选模；相同成绩保留较早 checkpoint。无官方验证集时默认固定配置和 30 epochs，使用最终 checkpoint。若另做训练集内部验证，单独记录划分及实验配置。最终测试不用于每轮挑选最佳模型。
- 受控噪声训练、训练期 NAC、冻结/微调选择等补充约定，随配置和结果一起报告；不把恢复后的指标当作历史结果。

## 4. 后续公共接口契约

| 接口/字段 | 约定 |
| --- | --- |
| 原始元数据 | 保存 `source_pid`、稳定的源图 ID、图像路径、split、caption 来源；新生成样本有独立样本 ID，并关联源图 |
| 训练标签 | `pids` 为训练身份的连续编号 `0…C-1`；分类数为身份数；评估身份另按数据集原协议处理 |
| 主输入 | `images: [B,3,384,128]`；`caption_ids: [B,77]`；`attention_mask: [B,77]`。输入不被 MLM 或腐蚀函数原地修改 |
| NAC 可选目标 | `clean_ids`、`target_valid_mask`、`corruption_mask` 分开；视觉 `detected_noise_mask` 在模型内计算，均为 `[B,77]` |
| 编码序列 | CLIP 图像为 CLS + 192 个 patch；文本保留 77 位置，特征末维 512；所有注意力明确 batch/sequence 维度 |
| 评估编码 | `encode_image(images)`、`encode_text(token_ids, attention_mask)` 返回 `[B,512]`；不接受 PID；同一样本不因评估 batch 组成或顺序变化 |
| 训练输出 | 明确的总损失、命名的原始损失项、独立指标；仅有效项进入目标，双模态分量不覆盖、不重复计数 |
| 设备迁移 | 只移动需要的张量；路径、来源等元数据保留在 CPU，不对整个 batch 无区别调用 `.cuda()` |
| checkpoint | 保存格式版本、模型及训练配置、模型参数、标签映射、epoch/step、优化器、调度器和随机状态；评估按保存的模型配置恢复；不依赖固定 `best0/1/2` 命名 |

训练数据流固定为：主输入编码 → NAC 检测/融合/生成/替换/重编码及样本选择（启用时）→ A2DFP 与残差融合（启用时）→ SDM、ID 和 CDFP（启用时）→ 总损失。NAC 的 `L_gen` 独立从有对齐目标的有效检测位置计算。检索损失使用纠正之后的表示。
